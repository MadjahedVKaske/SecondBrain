# Куда залить виджет (демо)

## Папка на сервере

Всё содержимое этой папки → корень сайта:

**`https://buro1.tech/b24-widget/`**

Должны открываться:
- `https://buro1.tech/b24-widget/index.php`
- `https://buro1.tech/b24-widget/clients.php` (JSON клиентов из 1С)

## Файлы

| Файл | Нужен |
|---|---|
| `index.php` | да - установка + роутинг вкладки |
| `tab.php` | да - UI вкладки |
| `clients.php` | да - прокси в Works API |
| `config.php` | да - URL/токен 1С |
| `config.sample.php` | можно не заливать |
| `КАК_ЗАЛИТЬ.md` / старые md | не обязательны |

PHP + **curl** на хостинге обязательны.

## После заливки

1. В браузере открой `index.php` - должна быть страница «Клиенты 1С».
2. Отдельно открой `clients.php` - JSON `{ "ok": true, "items": [...] }`.
3. В демо-Б24 локальное приложение:
   - обработчик: `https://buro1.tech/b24-widget/index.php`
   - установка: тот же
   - меню: `Клиенты 1С`
   - права: CRM
4. Установить → открыть сделку → вкладка → «Загрузить клиентов из 1С».

## Если 404

Проверь путь папки на хосте (часто `public_html/b24-widget/` или `www/b24-widget/`).
